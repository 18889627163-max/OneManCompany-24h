## 🔄 任务状态机

```
   CEO 输入
      ↓
  [PENDING] ────────────┐
      ↓                 │
  [PROCESSING]          │ depends_on
      ↓                 │ 未满足
  [COMPLETED]           │
      ↓                 │
  [ACCEPTED] ←──────────┘
      ↓
   结束
   
  异常路径:
  PROCESSING → [HOLDING] → (事件恢复) → PROCESSING
             → [FAILED]
             → [CANCELLED]
```

**关键状态说明**：
- `PENDING`: 已调度，等待执行
- `PROCESSING`: 正在执行
- `COMPLETED`: 执行完成，等待上级验收
- `ACCEPTED`: 上级验收通过
- `HOLDING`: 暂停（等待 CEO 回复、等待资源）
- `FAILED`: 执行失败（重试次数耗尽）
- `CANCELLED`: CEO 取消

## 🔑 关键类与方法

### EmployeeManager（核心调度器）

```python
class EmployeeManager:
    # 注册员工
    def register(employee_id: str, launcher: Launcher) -> Vessel
    
    # 推送任务
    def push_task(employee_id: str, description: str, 
                  node_id: str, tree_path: str) -> str
    
    # 调度下一个任务（内部方法）
    def _schedule_next(employee_id: str) -> None
    
    # 执行任务（内部方法）
    async def _execute_task(employee_id: str, entry: ScheduleEntry) -> None
    
    # 取消项目所有任务
    def abort_project(project_id: str) -> int
    
    # 取消员工所有任务
    def abort_employee(employee_id: str) -> int
```

---

### Vessel（员工视图）

```python
class Vessel:
    # 推送任务
    def push_task(description: str, project_id: str, node_id: str) -> str
    
    # 获取历史上下文
    def get_history_context() -> str
    
    # 查找任务
    def get_task(task_id: str) -> TaskNode
```

---

### Launcher（执行协议）

```python
class Launcher(ABC):
    # 执行一次任务
    async def execute(task_description: str, 
                      context: TaskContext,
                      on_log: Callable) -> LaunchResult
    
    # 检查是否就绪
    def is_ready() -> bool
```

---

### TaskTree（任务树）

```python
class TaskTree:
    # 获取节点
    def get_node(node_id: str) -> TaskNode
    
    # 获取激活的子节点
    def get_active_children(node_id: str) -> list[TaskNode]
    
    # 检查依赖是否满足
    def all_deps_resolved(node_id: str) -> bool
    
    # 保存到磁盘
    def save(path: Path) -> None
```


## 🚨 常见问题速查

### Q: 任务卡住不执行？

**检查清单**：
1. 员工是否已注册？`employee_id in employee_manager.executors`
2. 依赖是否满足？`tree.all_deps_resolved(node_id)`
3. 状态是否正确？`node.status == "pending"`
4. 是否有运行中的任务？`employee_id in _running_tasks`

**手动触发调度**：
```python
employee_manager.drain_pending()
employee_manager._schedule_next(employee_id)
```

---

### Q: Agent 说完成了但没有子任务？

**原因**：Stall Detection 检测到停滞

**排查**：
```python
# 检查输出
unfulfilled = detect_unfulfilled_promises(node.result)
unverified = detect_unverified_dispatch_claim(node.result, node.children_ids)

# 检查重试次数
retry_count = getattr(node, 'stall_retry_count', 0)
```

**手动重试**：
```bash
# 通过 API 重新推送任务
curl -X POST http://localhost:8000/api/task/retry \
  -H "Content-Type: application/json" \
  -d '{"node_id": "T003"}'
```
