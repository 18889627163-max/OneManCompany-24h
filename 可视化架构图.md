```

  ┌─────────────────────────────────┐
  │ 2. 创建 TaskTree                 │

  │    - 保存到 task_tree.yaml      │
  └───────────┬─────────────────────┘
              ↓
  ┌─────────────────────────────────┐
  │ 3. push_task(EA_ID, ...)        │
  │    EmployeeManager.push_task()  │
  └───────────┬─────────────────────┘
              ↓
  ┌─────────────────────────────────┐
  │ 4. schedule_node()              │
  │    _schedule["EA"] ← Entry      │
  └───────────┬─────────────────────┘
              ↓
  ┌─────────────────────────────────┐

              ↓
  ┌─────────────────────────────────┐
  │ 6. _run_task()                  │

  └───────────┬─────────────────────┘
              ↓
  ┌─────────────────────────────────┐
  │ 7. launcher.execute()           │
  │    EA Agent 开始执行            │
  └───────────┬─────────────────────┘
              ↓
  ┌─────────────────────────────────┐
  │ 8. EA 调用工具                   │
  │    dispatch_child(COO_ID, ...)  │
  └───────────┬─────────────────────┘
              ↓
  ┌─────────────────────────────────┐
  │ 9. 创建子节点 T002               │
  │    parent_id = "T001"           │
  │    employee_id = COO_ID         │
  └───────────┬─────────────────────┘
              ↓
  ┌─────────────────────────────────┐
  │ 10. schedule_node(COO_ID, T002) │
  │     _schedule["COO"] ← Entry    │
  └───────────┬─────────────────────┘
              ↓
  ┌─────────────────────────────────┐
  │ 11. EA 任务完成                  │
  │     status = "completed"        │
  └───────────┬─────────────────────┘
              ↓
  ┌─────────────────────────────────┐
  │ 12. _schedule_next("EA")        │

  ┌─────────────────────────────────┐
  │ 13. _schedule_next("COO")       │

  ┌─────────────────────────────────┐

## 🔄 状态机转换图

```
                    任务状态机
                         
        ┌───────────────┐
        │    PENDING    │  ← 初始状态（已调度）
        │   (待执行)    │
        └───────┬───────┘
                ↓ _schedule_next()
        ┌───────────────┐
        │  PROCESSING   │  ← 正在执行
        │   (执行中)    │
        └───┬───────┬───┘
            │       │
            │       ↓ (等待事件)
            │   ┌───────────┐
            │   │  HOLDING  │  ← 暂停（等待 CEO、资源）
            │   │  (暂停)   │
            │   └─────┬─────┘
            │         │ (事件触发)
            │         ↓
            │   (恢复到 PROCESSING)
            │
            ↓ (执行完成)
        ┌───────────────┐
        │  COMPLETED    │  ← 执行完成，等待验收
        │  (已完成)     │
        └───────┬───────┘
                ↓ accept_child()
        ┌───────────────┐
        │   ACCEPTED    │  ← 验收通过
        │  (已验收)     │
        └───────────────┘
        
  异常路径：
  
  PROCESSING ──(重试耗尽)──→ FAILED
            ──(CEO 取消)──→ CANCELLED

  状态检查点：
  
  ✓ PENDING → PROCESSING: 依赖检查 (all_deps_resolved)
  ✓ PROCESSING → COMPLETED: Stall 检查 (detect_unfulfilled_promises)
  ✓ COMPLETED → ACCEPTED: 父节点验收 (accept_child)
```

## 🔍 数据流追踪示例

**场景**：CEO 输入"写一个 Hello World 脚本"

```
1. 浏览器发送请求
   POST /task
   {
     "description": "写一个 Hello World 脚本",
     "assignee": "EA"
   }
   ↓

2. routes.py 处理
   def create_task():
     tree = TaskTree()
     root = TaskNode(
       id="T001",
       description="写一个 Hello World 脚本",
       employee_id=EA_ID,
       status="pending"
     )
     tree.add_node(root)
     tree.save("projects/hello_001/task_tree.yaml")
     
     employee_manager.push_task(
       EA_ID, 
       node_id="T001",
       tree_path="projects/hello_001/task_tree.yaml"
     )
   ↓

3. EmployeeManager.push_task()
   def push_task():
     self.schedule_node(EA_ID, "T001", tree_path)
     self._schedule_next(EA_ID)
   ↓

4. EmployeeManager._schedule_next()
   def _schedule_next():
     entry = self.get_next_scheduled(EA_ID)
     # entry = ScheduleEntry(node_id="T001", tree_path=...)
     
     self._running_tasks[EA_ID] = asyncio.create_task(
       self._run_task(EA_ID, entry)
     )
   ↓

5. EmployeeManager._run_task()
   async def _run_task():
     await self._execute_task(EA_ID, entry)
     # 完成后
     self._running_tasks.pop(EA_ID)
     self._schedule_next(EA_ID)  # 自动调度下一个
   ↓

6. EmployeeManager._execute_task()
   async def _execute_task():
     tree = get_tree(entry.tree_path)
     node = tree.get_node(entry.node_id)
     
     launcher = self.executors[EA_ID]
     result = await launcher.execute(
       node.description,
       context=TaskContext(...)
     )
     
     node.result = result.output
     node.status = "completed"
     tree.save(entry.tree_path)
   ↓

7. LangChainExecutor.execute()
   async def execute():
     # EA 决定任务需要分派给工程师
     result = await self.agent.run_streamed(
       "写一个 Hello World 脚本"
     )
     # Agent 调用 dispatch_child 工具
     # → 创建子节点 T002
     # → 分派给工程师 00021
   ↓

8. dispatch_child 工具执行
   child = TaskNode(
     id="T002",
     parent_id="T001",
     description="编写 hello.py 脚本",
     employee_id="00021"
   )
   tree.add_node(child)
   employee_manager.schedule_node("00021", "T002", tree_path)
   ↓

9. 工程师开始执行
   # _schedule_next("00021") 自动触发
   # → _run_task()
   # → _execute_task()
   # → LangChainExecutor.execute()
   # → Agent 生成代码
   ↓

10. 工程师完成
    node.status = "completed"
    node.result = """
    已完成 hello.py:
    
    print("Hello, World!")
    """
    ↓

11. EA 验收
    # EA 的下一个任务：验收 T002
    # 调用 accept_child 工具
    child.status = "accepted"
    ↓

12. EA 完成总任务
    root.status = "completed"
    # 项目完成，通知 CEO
    ↓

13. WebSocket 推送到前端
    {
      "type": "task_completed",
      "node_id": "T001",
      "result": "任务已完成，生成了 hello.py 脚本"
    }

## 💡 关键设计模式

### 1. 零空转调度
```
传统设计（轮询）:
while True:
    if has_pending_task():
        execute_task()
    await asyncio.sleep(1)  # ❌ 每秒唤醒一次

OMC 设计（事件驱动）:
def push_task():
    schedule_node()
    _schedule_next()  # ✓ 立即调度

async def _run_task():
    await execute_task()
    _schedule_next()  # ✓ 完成后才调度
# ✓ 空闲时无任何协程
```

### 2. 数据/指针分离
```
❌ 错误设计（数据冗余）:
class ScheduleEntry:
    task_description: str  # 业务数据
    result: str            # 业务数据
    status: str            # 业务数据
    # → 调度队列膨胀，数据不一致

✓ 正确设计（纯指针）:
class ScheduleEntry:
    node_id: str           # 只存 ID
    tree_path: str         # 只存路径
# → 轻量级，数据从 task_tree.yaml 按需加载
```

### 3. Git-Friendly 持久化
```
❌ 错误设计（数据库）:
PostgreSQL / SQLite
- 二进制格式
- 难以 diff
- 难以回滚

✓ 正确设计（YAML/JSON）:
task_tree.yaml
- 纯文本
- git diff 可读
- git revert 可回滚
- 人类可编辑
```
