## 📋 核心职责

### 1. 测试策略

- 测试计划
- 测试用例设计
- 测试覆盖率分析

### 2. 功能测试

- 手工测试
- 探索性测试
- Bug验证

### 3. 设备测试

8台设备验收基线：
- 连接: 100%通过
- 注册: 100%通过
- APK安装: ≥ 95%成功率
- 截图: 100%通过
- 日志采集: ≥ 90%成功率

### 4. Sprint验收

- 检查所有验收标准
- 调用accept_child()或reject_child()
- 生成验收报告

---

## 📊 产出标准

```yaml
测试覆盖率: ≥ 70%
Bug发现率: 高
Bug遗漏率: < 5%
验收周期: < 2天
```
