## 📋 启动前验证

在启动24小时模式前，**必须**确认以下修复已完成：

  - 测试：提交12个并发任务，验证不超过限制
  - 预期：任务排队而不是失败
  - 验证命令：`./scripts/check-system-ready.sh`

- [ ] **并发槽位管理**
  - 测试：查询可用槽位，获取槽位，释放槽位
  - 预期：槽位正确分配和释放
  - 验证：Python unit tests通过

- [ ] **派发幂等性**
  - 测试：相同task_key重复派发
  - 预期：返回已有node_id，不创建重复节点
  - 验证：Integration tests通过

- [ ] **显式验收机制**
  - 测试：Review节点未调用accept/reject
  - 预期：创建人工升级节点，不自动接受
  - 验证：Standard v2 iteration测试通过

- [ ] **workflow_contract_version = 2**
  - 测试：创建新iteration
  - 预期：自动设置version=2
  - 验证：检查task_tree.yaml

**总体验证**：
```bash

# 应该输出：✅ All P0 fixes verified
```

## 🚨 失败标志（需要停止和调整）

### ❌ 立即停止条件

- [ ] **COO父节点频繁失败**
  - 连续3次并发限制失败
  - 任务无法闭环

- [ ] **质量严重下降**
  - 自动接受仍在发生
  - P0 bug大量出现
  - 测试覆盖率 < 40%

- [ ] **系统不稳定**
  - 服务频繁崩溃
  - 数据损坏
  - 无法恢复

### ⚠️ 需要调整条件

- [ ] **并发问题**
  - 任务大量排队（>20个）
  - 员工长时间空闲

- [ ] **夜间无活动**
  - 夜间完全没有任务
  - 自动化测试未运行

- [ ] **成本超支**
  - 月度成本 > $5000
  - Token使用超预期
